# Suggested extensions: Basic hypothesis testing

The example report that you have been given for this set of exercises reviewed the theory of 
hypothesis testing that you may have learned in SOR1020. If you want to perform an extension 
of the work in the example report, you could present an analysis that is similar to the one that
has been presented in my example report but using something other than the normal random variables
for generating the $X_i$ values that were used to calculate the test statistic in my report.
However, my recommendation would be for you to continue with the next set of exercises and for you 
then to explore the test statistics that are used in one of the other hypothesis tests that you learned
about in the level one module.
