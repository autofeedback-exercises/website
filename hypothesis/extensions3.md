# Suggested extensions: Investigating the statistical power of a hypothesis test

The example report for these exercises presented an investigation of the statistical power of the 
hypothesis test for determining if two distributions are the same or different that you learned about
in the level one course SOR1020. In other words, I generated pairs of histograms from two samples of two
different random variables and investigated how frequently a test to determine if the distribution returned 
a false negative. You can do the same kind of investigation for any one of the statistical tests that you learned
about in the level one course.

The simplest thing to do would be to repeat the analysis that I did using estimates of $n$ distributions calculated
from $n$ different random variables. Remember that the test I used in my report can also be used to compare more than 
2 distribution. In SOR1020 you also learned about the following statistical tests:

* Comparison of means
* Tests of proportions
* Comparison of two proportions
* Tests of correlation coefficients
* Paired comparison tests (you learned multiple methods for doing this)
* Tests of slope and intercept in linear regression models
* Comparison of two variances
* Comparison of $n>2$ means
* Comparison of unkown variance with known variance
* Goodness-of-fit Test for Classified Data
* Sign test - single median
* Wilcoxon signed rank test - single median or mean
* Mann-Whitney Test
* Run Test for Randomness

Looking through your SOR1020 notes will allow you to understand the theory that underpins each of these tests. Understanding
that theory will give you ideas for generating model data that you can use to investigate the statistical power for each of 
these tests as has been done in the example report.
